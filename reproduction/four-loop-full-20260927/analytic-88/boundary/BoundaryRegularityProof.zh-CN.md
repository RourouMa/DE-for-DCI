# 完整88维边界常数：正则性与充分性证明

本证明针对已经冻结并独立验证的完整有理 dlog 系统 `four-loop-dlog-20260927/structure/Full88DLogCandidate.wl`。约定为 J=T I，原生积分顺序为完整88项列表。它不以数值积分的符合程度作为证明依据。

## 1. 原积分在 (x,y)=(1,1) 的复解析性

动量空间定义见 `four-loop-analytic-20260927/feynman_four.py`。外部点分成 A={1,3}、B={2,4} 两组，质量平方分别为 x、y。平方间距为

- 跨组的四个间距均为 x+y；
- q13²=−(1−x)²，q24²=−(1−y)²。

所有内部线都是质量为零的一次传播子。`PropagatorRegularityAudit.json` 逐项检查了完整88个原子的内部图都是森林，内部幂只有0、1，且每个积分点的“外部净幂+内部度数”等于4。有的原子包含外部传播子分子；不能把它们误当作所有传播子幂都非负的标量积分。

先考虑分母的 Schwinger 表示。令 A、B 同时表示两组所有外部 Schwinger 参数之和，M=A+B。将内部高斯变量消去后，定义有效电导 Cij，使

F/U = x A + y B − Σ(i<j) Cij qij²。

在这一约定中 Cij≥0；它就是边界网络 Schur 补矩阵的非对角元的负值，能量写为 Σ Cij(vi−vj)²，没有额外的2因子。跨组总电导 C_AB 等于把 A 组电势固定0、B组固定1时对所有内部电势最小化的能量。取所有内部电势等于 B/M 的试探值，立即得到

0 ≤ C_AB ≤ AB/M ≤ M/4。

所以实正 x、y 时

F/U ≥ x A+y B−(x+y)AB/M = (x A²+y B²)/M ≥ min(x,y) M/2。

同组间距的贡献是非负项，不削弱这个下界。特别地，F0/U≥M/2。Schur 补的迹不大于消元前边界块的迹 M，因此 Σ(i<j)Cij≤M/2。若 |x−1|、|y−1|≤δ，则对复参数也有统一估计

|F−F0| ≤ U M(3δ/2+δ²/2) ≤ (3δ+δ²)F0。

取 δ=1/10，右侧相对系数为0.31<1。此估计对 Schwinger 参数一致，包括趋近其积分边界的情形。

为同时严格处理外部分子，可以使用一个显式的共同积分轮廓。采用 Minkowski 分量

q1=0,
q3=(0,1−x,0,0),
q2=(Q,(1−x)/2,(1−y)/2,0),
q4=(Q,(1−x)/2,−(1−y)/2,0),
Q²=x+y+[(1−x)²+(1−y)²]/4。

在 Q=√2 附近选取解析平方根。对每个圈动量采用相同中心 q_c=(Q/2,(1−x)/2,0,0)，再 Wick 旋转其时间分量。原点处每个外部分母的实部为 |k_E|²+1/2；在足够小的统一复邻域内，其绝对值下界为 c(1+|k_E|²)，每个外部分子绝对值上界为 C(1+|k_E|²)。因为所有圈动量使用同一平移，内部传播子仍是 |k_i−k_j|^(−2)。这条轮廓与既有正传播子/低于阈值的解析延拓一致。

因此每个原子的绝对值都由下列与外部参数无关的可积函数控制：

C ∏_i(1+|k_i|²)^(−e_i) ∏_(ij∈E)|k_i−k_j|^(−2)，

其中 e_i 是包含分子后的外部净幂，e_i+deg(i)=4。用 Ω_i=2/(1+|k_i|²) 作 S4 立体投影，度数等式使每点的 Ω 幂与积分测度完全抵消。剩下的是紧空间 (S4)^L 上的 ∏_(ij∈E)|n_i−n_j|^(−2)。内部图是森林，可逐叶积分；单叶积分 ∫_(S4)|n−n0|^(−2)dΩ 有限且与 n0 无关。因此上述函数确实可积。这个论证包含全部外部分子，而不需要不合法的“分子自动无害”假设。

统一复邻域中的解析被积函数和可积控制函数，证明所有88个原积分 I 都在 (1,1) 复解析；它也许可积分号下的任意有限阶 Taylor 展开。四圈53项的共同值 B4 及低圈35个常数沿用已经认证的边界值。这里证明了此前仅有“有限值”尚未自动包含的更强正则性。

## 2. 为什么有理变换中的负幂最终必须消失

沿一般射线 x=1−a s、y=1−s，取 a=4 或5。原生 I(s) 解析，T(s) 有理，故 J(s)=T(s)I(s) 至多是具有有限主部的 Laurent 级数，本身不含 log s。

dlog 连接的拉回为

J'(s)=[R/s+B0+B1 s+…]J(s)。

R 是字母零点阶数乘以常数留数的和。所有留数在同一个无环依赖顺序中严格三角，所以 R 是幂零矩阵；精确检查 R^10=0。

假设 J(s) 有非零首项 v s^(−m)，m>0，则最低阶方程给出

(−m I−R)v=0。

由于 R 幂零，−m I−R 可逆，这与 v≠0 矛盾。因此全部负 Laurent 幂必然抵消，J(s) 在 s=0 解析。其常数 c 必须满足 Rc=0。

这不意味着可以直接把 T 和 I 各自取极限。实际 T 在高圈8行含最高二阶极点，对低圈列含最高四阶极点；本次计算显式处理了相应 Taylor 系数，见下一节。

## 3. 两条独立的精确边界计算

前向路线由本目录记录：

1. 从已认证 `Lower35Functions.wl` 的35个明确 GPL 函数，先对1−y展开至4阶，再对1−x展开到所需的总次数4；保存于 `LowerTaylor1.wl` 至 `LowerTaylor35.wl`。
2. T 的负高圈幂只乘12个仅含低圈源的原子，即18…23、41…46。这12行本身的高圈T块有限，因此它们的 canonical 常数可由 B4 和低圈 Taylor 系数直接取得。
3. 利用已验证的低圈及这12行 dlog 方程产生所需的5阶 canonical Taylor，再回代 T^−1 得到12个原生积分所需的一、二阶 Taylor 系数。
4. 将这些系数代回其余8行。两个一般斜率4、5分别验证全部负阶为零、12个原生值等于 B4、完整 Rc=0。

主验证器另外使用全局逆向路线：令 J(s)=Σ P_n c s^n，以 T^−1(s)J(s) 的全部负阶为零及88个常数项等于原生边界值构造纯常数线性方程。704×88约束矩阵秩为88。

`IndependentBoundaryCrossCheck.json/.wl` 证明前向路线与全局逆向解的88项结果逐项精确相同；两个一般射线也逐项精确相同。此外，在 (1,1) 消失的8个字母，各自的留数矩阵都单独湮灭 c。所有检查均为精确恒等式。

## 4. 边界常数足以唯一确定局部解析解

写 J(s)=Σ_(n≥0) v_n s^n，v0=c。由于 Rc=0，对于 n≥1 有

(n I−R)v_n = Σ_(k=0)^(n−1) B_k v_(n−1−k)。

n I−R 恒可逆，逆矩阵可写成有限和 Σ_(j=0)^9 R^j/n^(j+1)。所以全部 Taylor 系数被 c 唯一确定，没有额外自由 Taylor 初值。系数矩阵的解析部分在最近非零字母根以内解析，且上述逆矩阵范数为 O(1/n)，标准级数优函数估计给出这个 Taylor 解的局部收敛性。之后可以沿避免字母零点的路径作解析延拓，完整精确平坦性保证同伦内的一致性。

还可证明普通极限不依赖一般射线斜率。由 I 的二元解析性和 T 的有理性，有限首项 c(a) 是 a 的有理函数；其角向连接是只有 a=0,±1,±2,±3 及无穷远简单极点的常数留数系统。所有这些留数以及无穷远留数都在同一严格三角顺序下幂零。上节最低幂论证排除了 c(a) 在任一有限点或无穷远的极点，所以这个有理函数只能是常数。这也解释了两个一般斜率的精确符合及8个消失字母各自的湮灭条件。

这里得到的是完整边界常数及其确定解析解的充分性。它不能把尚未完成的通用点直接积分数值比较自动视为通过；该比较应另行报告其收敛和误差。
