# 经典 UD ladder 闭式对本 top 的适用性

本 top 的图连接确实是四点四圈 ladder，但经典 Usyukina–Davydychev 无质量闭式不能直接代入当前质量与运动学。这个结论只排除直接套用标准公式；它不排除另行建立含质量推广、积分变换或特殊恒等式。

原生第1个积分的非零传播子为

\[
 (X_1Y_1)(X_3Y_4)
 \prod_{i=1}^4(X_2Y_i)(X_4Y_i)
 \prod_{i=1}^3(Y_iY_{i+1}),
\]

每项幂次均为1。它共有10条外点–积分点边、3条积分点–积分点边，各积分点度数4。这与 Loebbert–Stawinski 文中式(2.5)的 ladder 连线一致。[原文 §2.1](https://arxiv.org/html/2408.15331v1#S2.SS1)

不过，项目的独立动量空间定义 `feynman_four.py` 使用

\[
 D_{ai}=(k_i-q_a)^2-m_a^2,\qquad
 (m_1^2,m_2^2,m_3^2,m_4^2)=(x,y,x,y),
\]

而链边为 \((k_i-k_{i+1})^2\)。因此在 \((x,y)=(1/4,3/4)\)，其中2条外点边的质量平方为1/4，另外8条为3/4，只有3条链边无质量。标准 UD 文献中的“外腿任意 off-shell”允许外部动量平方非零，但其环积分内部的物理传播子仍全部无质量；外腿 off-shell 不能替代内部线质量。[Davydychev 原作者说明](https://arxiv.org/abs/hep-ph/9310308)

从参数积分也能看出直接替换为何无效。以一个含四条外点传播子的顶点为例，取 \(\sum_a\alpha_a=1\)，其二次形式为

\[
 F=\sum_a m_a^2\alpha_a^2+
 \sum_{a<b}(m_a^2+m_b^2-q_{ab}^2)\alpha_a\alpha_b.
\]

无质量情形的所有对角 \(\alpha_a^2\) 项为零，本家族则不为零。改变普通外部距离只会改变非对角项，非零参数重标度也不能把这些对角项消掉。在 embedding 表述中，这对应于质量非零的外点不在 null cone 上，而普通无质量外点在 null cone 上；保持二次型的共形变换及非零射影重标度保留这种区别。

Loebbert–Stawinski 的 §2.2 的确说明：外点传播子有质量、链边无质量时，conformal Schwinger 表示及相应维度递推可以推广。但紧接着 §2.3 明确专门化到全部无质量的 ladder；其后式(2.73)的经典多对数公式属于这个专门化。该文提供可研究的含质量递推方向，并未给出可不经推导直接替换本家族的 UD 闭式。[原文 §2.2–2.3](https://arxiv.org/html/2408.15331v1#S2.SS2)

所以此处没有用错误的无质量 UD 代值作为数值验证。现有 Chen 表达式与 DE 求值相符这一结果，以及原始四圈积分的直接数值比较，仍须分别评估。
