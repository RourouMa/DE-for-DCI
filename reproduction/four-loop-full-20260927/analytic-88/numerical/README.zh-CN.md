# 完整四圈 top 的独立高精度微分方程数值线

此目录读取已经精确验证的完整88维 dlog 方程和全局边界线给出的 canonical 常数，不读取直接积分估计来拟合常数。真实 top 已核对为原生第1个积分；其新基表示由完整逆变换的第1行导出，只有一个 canonical 分量。

## 两种数值方法

`dlog_taylor.py` 使用任意精度 Taylor continuation。先沿 `x=1−a s,y=1−s`（a=4或5）从正规奇点展开到 `s=1/20`，再沿直线到 `(1/4,3/4)`。每个字母沿直线路径是次数至多4的多项式，程序直接由多项式除法计算 `dlog` 的 Taylor 系数，无需数值微分。

若拉回连接写成 `R/s+Σ A_k s^k`，初值先检查 `R v0=0`。后续系数满足

`(n I−R) v_n = Σ_(k=0)^(n−1) A_k v_(n−1−k)`。

常数留数的联合依赖图已无环，R幂零；因此n≥1时按拓扑顺序解三角系统即可。正规canonical解的全部局部Taylor系数由v0确定。程序在两个不同初始射线、不同阶数和工作精度下运行，比较最终88个分量与top，避免只看内部截断估计。

`solve-ndsolve.wls` 另用Wolfram高精度展开生成初值，再用NDSolve的Extrapolation方法继续到目标点，独立交叉核对数值推进算法。

## 已完成的基础检验

完整88维连接中存在闭合的一圈4维子系统，其函数为 `2 log(x)log(y), −log(y), −log(x), 1/2`。Python方法在两条射线上与精确函数比较，最大误差分别为约 `7.2×10^-31` 和 `1.1×10^-36`；Wolfram Extrapolation方法的误差约 `9.6×10^-51`。详见 `OneLoopNumericalValidation.json` 与 `OneLoopNDSolveValidation.json`。

## 直接积分比较的边界

既有pySecDec随机QMC结果来自独立的四圈参数积分。两个加密run在目标点约为 `1.290980579 ±0.000745475` 和 `1.290183780 ±0.000700370`，没有达到原请求的相对误差 `10^-4`。其误差是随机QMC报告的统计估计。只有DE解完成后才读取这些值进行比较，不能把它们当成高精度解析参考或积分常数来源。

## 当前结果与直接积分配置修正

三种数值推进（两条Taylor路径及Wolfram Extrapolation）得到

`I_top(1/4,3/4) = 1.294977445434631202675686442291414292929`。

top最大差约 `4.52×10^-46`，88个canonical分量最大差约 `5.01×10^-46`，因此保守保留40位数字。88个原生积分值也已回代并保存，跨路径最大差约 `1.18×10^-45`；其中原有低30个积分与以前独立解析函数数值的最大相对差约 `1.03×10^-17`。

旧直接积分与这个结果不一致。进一步代码审计及常函数最小实验发现，共享Vegas对象的并发sector调用会错误替换当前被积函数指针；对已知总积分4的测试可算出2或3.94。该错误与DE无关，原始输出与代码见 `CONCURRENCY_AUDIT.zh-CN.md`。QMC路径也共享可变状态，但尚未独立重现其具体数值偏差。因此所有多sector线程的旧结果均保留但不作为验收依据。新的固定预算对照按sector串行，QMC内部仍可并行；最终是否通过直接积分检验以这些对照结果为准。

旧 `(1,1)` 边界QMC也采用多sector线程，故同样退出验收；其与B4接近不构成例外。精确B4的径向/谱推导和约90位交叉核对独立于这些QMC。

单独的串行 Vegas 对照也发现跨 sector 重复 seed 的相关误差风险（已知函数实验精确复现），所以不能把排除并发等同于报告误差已可靠。最终直接对全部1492个被积函数的同点总和作单次积分，使总误差无需假设sector独立。低首轮QMC及其他未达精度的尝试，其状态及全部原始输出均保留。

边界补充串行QMC现已完成：两个seed分别给出 `0.112189582673036567 ± 4.61371823710e−6` 与 `0.112189889377692309 ± 4.30943485378e−6`，均与独立解析 B4 在一个报告误差内相容。它们支持边界值，但没有达到预设 `10^-5` 相对精度目标；不能表述成达到该目标的高精度验证。比较记录为 `BoundaryDirectSerialComparison.json`，旧并发QMC仍排除。
