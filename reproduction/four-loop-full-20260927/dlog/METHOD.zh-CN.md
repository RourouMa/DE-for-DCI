# 完整 88 维 dlog 基的构造方法

## 结果与约定

固定原生原子基 `I` 的顺序为 53 个四圈、24 个三圈、7 个两圈、4 个一圈积分；原方程为 `∂z I=A_z I`。构造可逆有理矩阵 `T(x,y)`，定义 `J=T I`。新连接为

`B_z=(∂z T+T A_z)T⁻¹`。

`Full88DLogCandidate.wl` 给出了完整 T、T⁻¹、Bx、By 和 18 个常数留数矩阵。两方向同时精确满足

`dJ = [Σ_k C_k dlog W_k] J`。

字母集合为

`{x,y,1±x,1±y} ∪ {x±y^k,1±x y^k : k=1,2,3}`。

全源项 gauge 恒等式与完整常数 dlog 重构在构造阶段已逐项精确验证。完整原生 88 维的左右逆、双变量 gauge、符号曲率与 dlog 重构由 root 的独立分片程序再次检查。最终证书以其验证输出为准。候选文件已冻结，SHA256 为 `90922fd24225c32d50cd2c65c4ff03465d7bc56b73ef910c05b2d2ea9f7f78d6`。

## 1. 先分析完整连接，再选择基变换

联合 x/y 依赖图有 61 个 SCC：17、4、八个2以及51个1。17维块位于最高四圈，4维块位于低圈。原分母共23个不同有理不可约候选因子，最高极点为5阶，复杂表达式主要集中在四圈到低圈的源项。

这些分母因子不能直接视为最终 dlog alphabet。最终有理规范变换精确消除了五个原始因子：

`1+x², 1+y², 1+y⁴, 1−y²+y⁴, P=y(1+x²)²−2x²(1+y²)`。

保留全部 x/y 方向的联合依赖结构很重要；只按一个方向分块、只在一个变量中 Fuchs 化，都不足以保证双变量 dlog。

## 2. 低35维：旧解析映射用于发现基，而非直接当成可逆变换

旧的解析函数表示存在常数线性相关关系，直接使用旧解析转移矩阵并不能得到低30维原生空间上的可逆规范变换。正确步骤是：

1. 识别旧 canonical 函数实际31维常数空间中的相容商空间，取到29维有理 embedding。
2. 对这个29维 embedding，精确验证两个变量的原生低30维微分方程恒等式。
3. 在原生30维空间补足1个方向，得到真正可逆的30×30有理矩阵；通过 FiniteFlow 的有理线性算法求逆。
4. 对补足方向做标量积分因子归一化，再按三角依赖关系做有理 Hermite 剪切，消除补基产生的高阶极点与临时分母。
5. 加入5个新低圈方向，对其分别归一化，并包括这5个方向之间以及它们到旧30维的全部真实反馈项。
6. 从原生35维矩阵重新回代形成最终连接，精确验证左右逆、两个方向的 gauge 恒等式及14字母常数 dlog 分解。

旧解析数据只用来发现候选变换；没有把旧DE或解析关系作为新增物理IBP方程，也没有把非可逆的解析映射误当成完整35维基变换。

## 3. 最高53维：小块有理规范、联合无环结构与高圈内部剪切

最高圈先按 x 方向较小的有理块处理：2×2、3×3、4×4以及6×6块。由相应齐次解提取有理基，显式构造小块的 T 与逆矩阵。随后处理 y 方向残留的2×2循环，直至两个变量的联合依赖图都变成单元素块。

消去全部对角项后，依照依赖图从没有其他高圈依赖的行开始，逐行提取有理全微分部分并做三角剪切。最高53维得到16字母的常数 dlog 连接；两方向原生 gauge 与互逆关系均精确为零。仅最高圈成功还不代表完整系统成功，因为其四圈到低圈源项必须同步变换。

## 4. 完整源项必须带上高、低两侧反馈

先应用高低圈块对角规范：

`H=T_h I_h, L=T_l I_l`，`Q_z=T_h A_hl,z T_l⁻¹`。

再令 `Hnew=H−R L`，则

`Qnew_z=Q_z+B_h,z R−∂z R−R B_l,z`。

不能遗漏 `B_h R` 或 `R B_l`，也不能只对 Q 的每个元素独立做普通积分。实际算法是：

- 高圈行按依赖顺序处理，使当前行依赖的 R 行已经完成。
- 低圈列按反向依赖顺序处理，使当前列依赖的本行 R 元素已经完成。
- 对有效的一对一形式进行有理 Hermite 约化：先提取 y 方向的有理原函数部分，再对扣除该部分后的 x 分量提取有理原函数部分。
- 将剩余一形式保留为新的源项，最后对整个矩阵同时拟合常数 dlog 系数并做符号恒等式验证。

最先处理的12个高圈 source-only 方向已经独立通过14字母 dlog 验证。其后把53行分为4个 worker 组，按拓扑序等待必要依赖；每个结果记录相同输入 SHA256，用临时文件写入后原子重命名，避免读到半写结果或混用不同基。全部53×35源项完成后统一组装完整88维连接。

完整变换和逆矩阵使用显式块公式：

`T = {{T_h, −R T_l}, {0, T_l}}`，

`T⁻¹ = {{T_h⁻¹, T_h⁻¹ R}, {0, T_l⁻¹}}`。

## 5. 验证原则与失败经验

常数 dlog 拟合仅在有理数采样点上建立常数线性系统，随后必须对完整 x/y 符号表达式精确重构为零。没有对大型含运动学变量矩阵调用 symbolic RowReduce；小块显式有理变换、常数有理线性代数及 FiniteFlow 求解各司其职。

此前曾单独对全部51个单元素SCC构造有理积分因子。虽然两方向梯度恒等式全部正确、对角项消失，Ax/Ay非零元也下降，但最高极点反从5升至6，源项最大分母总次数从52升至56，y方向高阶极点项也增多。这个尝试被保留为诊断，未用作最终结果。

因此不要以“对角为零”“单块更短”或“某个方向只有简单极点”为最终优化标准。更可靠的顺序是：完整原生方程闭合 → 精确可逆高低块变换 → 两方向联合三角结构 → 带双侧反馈的源项剪切 → 整体常数 dlog 精确重构 → 独立原生 gauge 与曲率复核。

本文件记录 dlog 构造阶段的方法。后续已结合独立边界条件完成全部 53 个四圈及 35 个低圈积分的解析函数、迭代递推和归一化验证，见 [解析结果](../analytic-88/README.zh-CN.md)。可复用的分解与验证工具已整理为 [Adapters/DLogTools.wl](../../../Adapters/DLogTools.wl)。
