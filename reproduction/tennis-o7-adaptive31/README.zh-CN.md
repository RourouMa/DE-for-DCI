# O7 自适应原空间选基：三圈齐次闭合工件

`HighestLoopDE.wl` 包含 31 个单独有限基、x/y 的 31×31 矩阵、全部低圈源项、有理重构规则和完整池通用点比较记录。原 top 保留在第 18 项。`HighestLoopCurvature.wl` 记录 24 workers 对 961 项的精确零检查。

**此工件不接受为物理闭合结果。** 后续完整 47 维装配的曲率有 125 个非零项，联合关系池可把非零一圈 box 消成零，已有 311 条关系的精确矛盾证书。31 维齐次曲率为零仅是旧关系池模低圈源项的代数结果，不能证明该池物理正确。修正生成器后重新生成全部关系，已获得[单独保存的新完整 46 维结果](../corrected-three-loop-20260923/README.zh-CN.md)；新验收不适用于本目录旧矩阵。读取前先加载 package；结果中的 G、BoundaryIntegral、x、y 是 Wolfram 符号。

`production-ordering.wls` 冻结了本次三圈生产分支的 O7 排序。它覆盖私有排序函数并假设三圈索引长度，只适合隔离复现实验，不能加载到同时处理一圈/二圈的通用 package 会话中。

`manifest.json` 记录文件 SHA256。完整 332672 行关系池留在生产工作区，没有随此小型工件分发；这里可以检查已导出矩阵及曲率，不能仅凭这些文件重建全部 IBP 搜索历史。策略、验证层级与通用接口见 [原空间选基说明](../../docs/PRESERVE_ACTUAL_SPAN.zh-CN.md)。
