# 0.6.0：有限覆盖与方向链策略

更新日期：2026-09-27。四圈 ladder 完整 88 维系统已闭合，dlog、边界和解析函数已完成；后续 tennis court 按 [迁移流程](FOUR_LOOP_TENNIS_WORKFLOW_20260927.zh-CN.md) 单独计算。

## 已整合的策略

- 用完整物理池给出的数值秩见证和 FiniteFlow 有理坐标重构，分别记录实际联合秩和有限覆盖项数。三圈压缩路线保持实际空间；四圈先用低幂简单有限覆盖推动闭合，允许暂时扩大覆盖空间，闭合后再压缩项数。
- 四圈覆盖浮动按相对超额 `(覆盖项数−实际秩)/实际秩` 定标；三圈有效历史最大值为 1，乘以 150% 后为 3/2。`MaxRelativeCoverExcess -> Automatic` 使用此上限，每轮按当前秩取整，仍尽量贴近秩；它不是覆盖项数目标。
- 优先常系数、短支撑、低幂有限代表，加入常系数块候选和精确常系数高幂消去；所选有限代表必须满足外点—圈点分母正幂不超过 3、圈点—圈点分母正幂不超过 2；负幂分子不计入。限制不删除物理 IBP 行或导数目标。必要的运动学系数组合完整求导，包含系数导数。
- 可把已知独立有限定义作为 `FiniteReferenceBasis` 坐标参考；每轮在当前物理池内重算其坐标，只选择实际空间所需的组合。旧 DE 矩阵不充当物理关系。
- 按固定其余指标的方向链追踪首次出现轮次。累计至少三次增长时停止接受新轮次，扩大 IBP/symmetry 或补入有证明的物理线性关系，然后从 Top 重放。同池断点续算保留链历史。
- 四圈工作门槛为实际输入＋两方向导数的有理秩 70。它是修复关系的触发条件，不是已证明的 MI 上限，也不用于截短基。
- 物理求导缓存绑定 family、关系池、输入和源码；完整物理池保留源项；不能映射的非基源项保留为未知量，必须在完整坐标重构中消去。最高圈闭合与完整含源闭合分别验收。
- 原生关系生成采用保持原顺序的收集方式；常系数块通过一次系数表提取与稀疏组装代替重复逐单项式提取。实际 tennis 第四轮的 9,689 个块与旧算法完全一致，独立对照中该步骤约 14.6 秒降到 2.2 秒；不是整个 DE 运行的加速比。

- 整理原生线性表达式时保留标量系数的因式形式，避免展开高次多项式；保留旧展开路径处理形式上非线性但可相消的输入。原生求导与旧路径的有理表达式等价、变量系数求导及完整回归均通过。

当前 package 的 [52 组回归](VALIDATION_0.6.0.json) 全部通过，包括比例缩放、独立秩与覆盖证书、完整物理池缓存校验和求导等价性。

## 2026-09-27 选基经验（后续沿用）

三圈对照表明，压缩到更少的覆盖项会引入很长的运动学系数组合，并显著增大 DE 矩阵元。后续优先原子积分和短常系数组合，允许合理多一些覆盖项；每次压缩同时比较矩阵复杂度并重新验证闭合。此经验、量化对照和实施约束见 [有限覆盖复杂度经验](FINITE_COVER_COMPLEXITY_LESSONS.zh-CN.md)。
