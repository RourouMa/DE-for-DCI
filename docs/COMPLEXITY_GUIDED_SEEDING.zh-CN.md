# 用候选积分复杂度指导 IBP 扩充（0.3.5）

目标是最高圈 DE 闭合且有限基尽可能简单。有限覆盖、当前方程池中的自由列、真正独立的主积分是不同概念。不能因为 `G -> G`，或一个复杂积分恰好单独有限，就直接把它送进下一轮微分。复杂度是调查线索，不是可约性的证明；没有关系就不能删掉它。

## ordering 与有限基策略必须分开记录

指定 ordering 定义优先保留的不可约代表。严格排序实验只保留约化后的单独有限原子，并在剩余原子中构造有限组合；不能反解约化规则，把原查询中已消去的积分重新选作代表。`finiteBasisContract` 在每轮接受基时检查是否引入正规形支撑之外的原子、是否遗漏单独有限的代表。变量系数的证据评估不自动授权换一套代表。

`PreserveActualSpan` 是另一种选基策略：它可能利用已约化的有限查询覆盖实际 DE 空间。这可以产生有效且简单的闭合系统，例如已验证的 ladder19，但不是原 ordering 的严格自由列结果。用户明确要求保留这条实验路径时，应以独立的“ordering＋选基策略”名称记录，与严格排序对照，不能把收益全部归于 ordering。若要把该基直接作为约化优先代表，需显式定义新的 ordering 并验证。见[历史审计与实验边界](ORDERING_PREFERENCE_AUDIT.zh-CN.md)。

这套判断适用于所有 ordering、严格排序分支、自适应有限覆盖分支及其他 family。不能只对用户举例或当前主线做审查。每轮应综合拓扑自然幂次、分子与分母补偿、候选在各 DE 行中的作用、完整有限组合、可能遗漏的 symmetry/IBP 以及历轮复杂度增长，决定是继续微分、复用已有关系，还是定向补关系。具体数字阈值只排序调查优先级，不能代替这些判断。严格 ordering 限制代表选择，不免除关系充分性调查。

## 逐轮判断

对完整有限组合的每个原子，以及已有规则给出的规范形，记录 sector、正幂总和 r、正幂槽数 t、分子次数 s、dots=r−t、最大正负幂、连通分量和各圈权重。末尾单位 cut 指标不计入 r、t、s。比较应在同 family、同 sector 或真实允许的子拓扑中进行，不把横向 ladder 的经验直接套给所有 tennis-court 子拓扑。

分子与分母幂次共同增长不自动意味着可约。默认采用分级经验：共同增加1属于正常候选；共同增加2少见但可以合理，例如 `(0,0,1)→(-1,-1,3)`、`(0,1)→(-2,3)`，单凭这点不阻止推进；共同增加3及以上是强烈可疑信号，优先检查已有约化、代表选择和关系缺口，仍不是可约性证明。

实现用 `JointExcess=Min[s,dots]` 作为相对于零分子、正幂为1的粗略统计，记录 `GrowthLevel`；只在 s≥3 且 dots≥3 时默认触发强复杂度审查。它不是所有 sector 的精确增量，更不是普适主积分上界，需结合实际子拓扑的自然幂次基线。`ComplexitySectorProfiles` 可提供本 family 的已验证参考，必须记录 `FamilyHash, Sector, Score, Evidence`；比某个简单参考复杂只是记录信号，不能单凭这个差异把一次或二次增长判为可约或强制拦截。之前 s≥2、dots≥2 的默认拦截已撤销。

用户点名的积分只是识别模式的例子，不是待处理白名单。每轮扫描全部新候选及其正规形，记录分子次数与分母升幂是否共同增加、是否偏离相同权重和真实子拓扑的已验证简单代表，以及复杂度是否随微分轮次持续恶化。调查对象必须自动来自整个候选集合。

这里“正规形”仅指依照当前方程池及 ordering 消元后的表达式。其未消去的代表不自动等于真正主积分，也不自动单独有限；相同物理方向在不同 ordering 下可以有复杂程度不同的表示。

`PhysicalCandidates` 保留每个完整候选表达式、整体有限性、内部发散原子和覆盖搜索目标。**有限组合的覆盖单位是整个组合**；其中一个发散原子不能被单独有限积分覆盖，不能推出组合缺少覆盖，更不能据此无限扩大 IBP。`Records` 中的原子信息用于定位关系缺口，不能替代完整候选的空间检验。严格排序模式在当前正规形支撑中选有限组合；另选有限代表的实验必须单独命名。实际表达式行秩只是诊断量，不能据此悄然改变已声明的选基策略。

1. **候选尚未查询**：先在已有完整方程池中约化，不能立刻撒点。
2. **复杂候选已有简单规范形**：沿指定 ordering 使用该规范形，验证完整表达式覆盖；不反解已有规则来重新引入已消去的查询。
3. **规范形仍含可疑复杂积分**：调查能够在固定 ordering 下进一步消去它的缺失关系，包括真实允许 sector 与 supersector 中的 IBP、factorized symmetry。简单积分的逆向覆盖不等于新增关系。以残留项做精确 operator 逆移位撒点，逐 operator 枚举能产生目标项的 seed，检查非零系数、共形权重和已声明域，再由完整 IBP（含 contact）验证。只增大分母或只增大分子的一维轴向邻域可能漏掉需要同时转移幂次的 seed。
4. **一层逆移位不足**：检查未消去的复杂邻居、被拒绝的 contact/domain 类型，以及真实的横向/纵向 factorized 子拓扑。只有需要时才扩大相应壳层、允许 supersector，或检验成组 action 的合法抵消（`FindCoupledIBPRelations`）；不能丢掉不合法项后把剩余部分当关系。

当前 API：

```wl
audit = AssessBasisComplexity[family, basis, reduction,
  "EquationPoolHash" -> Hash[equations, "SHA256"]];
plan = GenerateSeeds[family, audit["TargetedSeedTargets"], Automatic,
  "SeedGeometry" -> "InverseTargets", "SeedDomain" -> "Extended"];
(* Extended 仍受 family 已声明的域约束，不是任意 supersector。 *)
```

`GenerateSystem` 同样支持 `SeedGeometry`；完成的实际 operator–seed 配对仍按原有账本去重。原有 component-axial 默认模式保持不变。规范形比较、复杂度参考及定向 shell 扩充不改变 O7 ordering。

## 接受扩充与推进微分的条件

保留旧池和已验证规则。对候选增量同时比较：(a)复杂目标的规范形是否变简单、(b)输入及输入＋DE的实际秩、(c)有限覆盖是否完整、是否新增复杂代表。**秩不变并不意味着关系无用**，它可能把难看的代表替换成简单代表。反之，原始支撑项数增减都不能单独证明好坏。报告所用复杂度度量及其局限。

每次真正扩充主池，都把新增支撑对应的 ordinary/factorized symmetry 放到相同的已声明 supersector 域中处理，再从原始 top 重放。保持同一 ordering、generic point 和比较对象；扩大池后旧查询的秩不能无故增加。单点 FiniteFlow 用于候选筛查及最终 IBP 残差验证，符号重构可能需要多点，两者不能混称。

`RunDE` 在现有输入约化后、接受新的有限基前均调用复杂度门槛。触发时保留全部积分、规则、未验证行与审查记录，返回 `ComplexityReviewRequired`，而不是继续微分或宣称闭合。这个结构化状态是自主选择下一种修复策略的入口，不要求用户批准。它尚不自动尝试所有 shell/coupled 策略。

复杂积分并非永久禁止。如果定向撒点、symmetry 和简单基比较支持暂时保留它，可提供 `ComplexityDecision`，记录 `Reason, TargetedSeedAudit, SymmetryAudit, SimplerBasisComparison`，并绑定本次 `FamilyHash, BasisHash, EquationPoolHash`。这是有证据的判断，不能只写“用户允许”或用旧池的决定放行新池。常系数组合优先，变量系数的评估仍遵循原有有限基约定。最高圈未闭合前不转去做低圈闭合。

## 独立 tennis-court O7＋自适应有限覆盖实验记录（2026-09-23）

这里记录的是采用自适应有限覆盖的分支，不是严格 O7 自由列对照。E1 第四轮有限基有35个元素；下一轮输入＋DE秩54，商空间19维。不能把19叫作19个新增有限主积分。对35个元素中的原子审查，24个触发联合幂次增长，只有4个在已有规范形下保持自身。针对复杂候选及其残留规范形选出39个目标，复用此前391条独立候选关系，再尝试4761个 operator–seed 配对，生成3797条不同的非零关系。与已有候选和相应 symmetry 合并、去除旧池已有关系后，增量为4684条。

同一 generic point 的 FiniteFlow 筛查：输入秩35→31，输入＋DE秩54→37，差额19→6。它证实这批有针对性的关系有效；**不是符号约化验证、最终主积分数或闭合证明**。扩充池的符号重构和 E2 原始 top 重放另行记录。
