# 四圈完整源项闭合的经验

最高圈闭合与包含低圈源项的完整闭合需要分别报告。本次四圈最高块始终为53项；在加入原30项低圈覆盖后，83项的联合导数秩为88。严格消去已有基后，新增方向全部属于三圈，不是四圈新增主积分。

把最高块活跃源项作为目标，新增77,412条完整原生三圈关系，仍未消掉这五个方向。直接查看余项坐标后，五个方向可以选择为五个有限积分原子，外点—圈点最高幂2、圈点—圈点最高幂1。将这五项加入低圈覆盖，35项的导数曾显示37维；再针对这五项及其原生导数生成15,798条关系后，联合秩回到35，得到了闭合的有理微分方程。

因此，需要区分两种情况：低圈覆盖原本没有包含所需的独立方向，以及已有目标缺少足够的IBP / symmetry关系。应先定位余项所在圈数和具体积分，再针对新增代表及其导数补足关系。不能仅因最高圈商空间已闭合就宣称完整系统闭合，也不能仅凭某个有限域点的新增方向就宣称发现了不可约主积分。

新低圈系统为24项三圈、7项二圈、4项一圈，全部单积分。它已经通过三点原生完整物理池复核，全部1,225个符号曲率元素精确为零。原30项的DE不依赖新增5项，原有解析工作可保留。

对应完整四圈候选为88项，最高圈53项不变。在完整原生物理池中，88项与全部导数的秩均为88。完整有理矩阵及验证状态以 reproduction/four-loop-full-20260927 下的实际证书为准；有限域秩闭合本身不替代有理重构和符号曲率检查。
