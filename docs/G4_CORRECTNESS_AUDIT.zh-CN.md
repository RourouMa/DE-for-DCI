# 四圈有限性复核与回溯补点（2026-09-20）

0.2.5 修复了 `Do` 内 `Return` 未把失败传出外层函数的问题。旧的四圈有限基计数不能直接沿用；精确矩阵残差只验证代数约化，不替代积分有限性判定。

在本地 242433 条去重关系池上，原第二轮 14 个输入中有两个裸 G 各自含 `{1,2}`、`{3,4}` 两处对数碰撞，旧检查错误放行。它们的差在允许的 loop 和外点对称平均后，六个单碰撞及三个不相交双碰撞的点态留数全部精确为零。单独裸 G 及两项之和的负例留数不为零。

独立复现该特定组合的检查：

```sh
WolframKernel -script Examples/disjoint-collision-certificate.wls
```

这个例子检查两个具体差组合，共 14 项检查通过；它只认证这些组合的内部碰撞抵消；不放宽默认 `FiniteIntegralQ`，不泛化到重叠碰撞，也不宣称 DE 闭合。

采用这一显式证书重建第二轮，得到 13 个有限输入（10 个单积分、3 个常系数组合），精确覆盖原行。第三轮支持为 56 个裸 G；两次有限域抽样均得到输入秩 13、输入加导数秩 28，新增方向数为 15。有限组合覆盖仍失败；不能把它称为已经验证的闭合 DE。

GitHub 主分支 `506532d` 的 `docs/UBUNTU_HANDOFF.zh-CN.md` 记录旧 Mac `ordering01` 第三轮为：12 输入、50 raw G4、13 个单独有限积分加 13 个组合、26 个下一轮输入，没有未组合裸发散输入。原始大型矩阵和逐项基底未随仓库提交。这条归档记录与本次计算并非同一关系系统、ordering 或输入空间，且旧记录的 admission 也不声称覆盖所有收敛区域。

按用户要求，下一步实验已对当前全部 56 个裸 G（包括未认证有限的项）及有限组合做形式求导，得到 426 个 targets。它们使用 Original 域、AllOriginalImages、Cartesian 块邻域撒点；197868 个候选应用中跳过 85360 个已完成应用，实际执行 112508 个，新增 31398 条不同关系，总池 273831。随后回溯同一组 13 输入及其第三轮导数。裸输入不会因此被标记为有限；最终结论以回溯精确验证为准。

Gram 对照也保持独立：旧 74 条候选加入前后目标表达式精确相同。另 160 条包含全部四个 loop 的主子式候选在旧池之外的 61054 列上满行秩，因此单独加入不能给旧变量新增约束。它们仍保留为将来与更多 IBP 联用的候选，不自动加入正式系统。
