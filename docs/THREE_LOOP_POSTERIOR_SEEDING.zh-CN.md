# 三圈后验撒点扩充经验

整理日期：2026-09-25。这里的“后验”指：先用当前合法方程池约化实际输入与导数，再由未覆盖方向和复杂残留决定下一批 seed/operator 应用。它不是把已知最终 MI 或成功 seed 表硬编码为通用策略，也不是有限域数值采样；有限域采样用于筛查和重构，IBP 撒点用于生成关系。

核心经验是：**完整表达式定位缺口，逆移位选种子，补全次数适配算符，同域补 symmetry，扩池后从原 top 重放，最后验证含低圈源项的完整 DE。** 少生成关系是优化手段；实际覆盖、简单程度、总时间和有效性才是验收依据。

## 1. 先判断缺的是什么，再决定是否撒点

先合并完整输入、导数和有限组合的系数，再在已有完整池中约化。只出现在中间 query、最终整行相消的原子不应驱动扩充；一个发散原子不能被单独有限积分覆盖，也不能代表包含它的整组合没有有限覆盖。

| 当前现象 | 优先处理 |
| --- | --- |
| 目标尚未查询，或导出文件缺规则 | 查询并核对现有池、缓存与导出；先确认确实缺关系 |
| 历史查询有 `UnseenTargets`，但完整实际表达式已有精确覆盖 | 分别记录查询覆盖与实际覆盖；不单凭历史原子缺失推断 DE 有缺口 |
| 复杂候选已有简单正规形 | 按声明的选基策略使用现有关系并验证完整覆盖 |
| 完整 DE 相对输入仍有未覆盖方向 | 从残差选目标，准备逆移位 seed 块 |
| `G -> G` 或正规形仍留有可疑复杂积分 | 检查缺失 IBP、合法域、factorized symmetry 和相邻辅助积分；“在矩阵中出现过”不表示已充分约化 |
| 常系数有限覆盖搜索失败 | 检查整组合、候选范围和实际空间；一次二项差搜索失败不证明常系数组合不存在 |

这张表是诊断流程，不表示 `RunDE` 已自动实现每条分支。特别是当前通用 `OnDemand` 路径仍将 `UnseenTargets` 用作生成触发条件；个别三圈续算脚本中按完整覆盖决定推进的修正，不能写成通用接口已有的保证。

设 `NF` 是固定方程池和 ordering 下的约化，取最高圈分量后记

```text
r_in    = rank NF(M)
r_joint = rank NF(M, d_x M, d_y M)
gap     = r_joint - r_in
```

低圈项仅在这个诊断秩中取商，必须在实际方程和验证中保留。`gap` 是当前输入的最高圈闭合缺口；原子数、未覆盖行数、有限覆盖基数、实际空间秩和全局 MI 数须分别报告。未知 MI 时，正缺口也可能是正常的新方向，不能要求每一轮都靠补关系将其消为零。

## 2. 逆移位用于选种子，完整算符块用于补关系

单坐标轴向 `+/-1` 邻域可能漏掉同时转移多个指数的旋转作用。对算符普通作用中的精确指数位移 `delta`，从目标 `t` 反推 `seed = t - delta`，检查目标系数非零、单位 cut、允许域和次数匹配：

```text
incidence . seed + operator_degree = {4, ..., 4}
```

一旦种子入选，就生成**全部次数适配算符**的作用，包括不直接含目标的作用；这些辅助关系可能消去中间积分。`InverseOperatorPolicy -> "Complete"` 保证的是选中种子相对于所供算符集的补全，不是所有 seed、所有 IBP 或局部闭合的完备性。

规划阶段的命中和次数检查不能替代完整 IBP 检查。每次作用都要检查 ordinary 项、contact、无穷远项、输出域以及整个低圈收缩源的可认证有限性。不能把域外项或发散源删掉后接收剩余关系。

局部一批无收益时，依次调查：未完成的适配算符、同域 symmetry、与残差相连的辅助积分、真实允许的相邻壳层及被拒绝的接触/域类型。必要时在支持的碰撞结构内用 `FindCoupledIBPRelations` 搜索完整作用的精确组合抵消。普通应用的拒绝记录不能直接压掉 coupled 搜索；不受实现支持的重叠碰撞也不能靠组合接口自动获得合法性。

## 3. symmetry、拓扑域和接触源必须同步处理

每批关系的新增支撑都需要相应 ordinary/factorized symmetry。因子块应允许独立外点变换及圈置换，实际 seeds 仍须满足选定域；先检查是否存在原域内合法 symmetry image，再判断是否需要已声明的 supersector。

`SeedDomain -> "Extended"` 只允许 family 已声明的合法扩展，不允许任意拼接环变量。Tennis 的横向、纵向 ladder 来自真实收缩与外点映射；低圈 family、导数方向和 symmetry 必须使用同一映射。已有低圈 DE 也要重新检查是否覆盖当前三圈产生的整行源项。

旧池曾因漏检连续碰撞产生发散二圈源，接入低圈关系后甚至把非零一圈 box 消为零。因此必须在**整个收缩源表达式**层面检查有限性；仅检查当前求导端点或最高圈齐次曲率不足。`UncertifiedContactSource` 表示当前实现不能认证，应记录并拒绝，不能解释成源项为零。详细复现见[接触源有效性](CONTACT_SOURCE_VALIDITY.zh-CN.md)。

## 4. 小批筛查，以实际收益决定扩充范围

按残差方向、sector、碰撞结构或相连辅助种子块分批。旧池与候选池使用同一 ordering、输入、通用有限域点和素数；奇异分母、学习失败或求值失败要拒绝该点，不能当成零残差。比较以下项目：

- `r_in`、`r_joint`、`gap` 及完整表达式未覆盖行；若输入也降秩，不能只报联合秩下降。
- 可疑复杂代表是否消去、完整有限覆盖是否更简单、是否引入新的复杂支撑。
- 候选/已完成/实际应用数、合法/拒绝数、新的不同非零关系数，以及生成、约化、重构和重放时间、峰值内存。

原始支持减少、关系行数增加都不能单独证明收益；“不同非零关系”也不等于“线性独立关系”。秩不变而代表显著变简单仍可能有用。后验成功 seed 清单只能作为调度线索，通用优化还要同资源、同输入、同验收标准的独立对照，不能把少几轮或少几行直接换算为加速比。

复杂度按同 family、同 sector 的自然幂次判断。记录分子次数 `s`、正幂总和 `r`、正幂槽数 `t`、`dots = r-t`、最大幂和碰撞结构，单位 cut 不计入。分子与分母共同增加一阶常见，二阶结合拓扑审查，三阶及以上优先调查缺关系；这都是经验信号，不能据此删除积分或断言可约。详见[复杂度指导撒点](COMPLEXITY_GUIDED_SEEDING.zh-CN.md)。

## 5. 增量账本、从 top 重放和有限选基

去重单位是 operator–seed 配对。当前普通应用键为 `{Hash[operator,"SHA256"], seed}`，其可复用性由 campaign 的 family 和实现指纹限定；一个 seed 做过某个算符，不代表整个块已完成。父进程先减去 `CompletedApplications` 再派发，并合并 symmetry 覆盖。未完成 worker 不计入完成台账，不能由关系条数反推已做应用。详见[增量去重](SEEDING_DEDUPLICATION.zh-CN.md)。

正式加入新关系后保留全部仍有效的旧关系，递增 epoch，同步 symmetry，并从原 top 重放所有历史输入、targets 与 RHS 代表元。只换有限覆盖不算扩池；只有缓存变化或生成零关系也不算扩池。已有精确覆盖恒等式可在有效池包含关系下复用，但新池的秩、规范形、复杂度和闭合必须重新判断。

生成器修正是例外：旧“通过”标志不能使旧关系继续有效。保存旧池供审计，重新生成或逐条认证，记录被排除关系和原因；不能修改 checkpoint 哈希假装与新版本兼容。本次三圈完整复核保留了候选基定义，但重新生成关系和约化，正是这种区别。

ordering 与有限选基策略分开记录。`StrictOrdering` 保留指定排序的正规形代表；`PreserveActualSpan` 可用已验证约化后的简单候选覆盖实际输入/DE 空间，须精确检查成员关系、独立性和覆盖。后者的收益不能全部归因于 ordering。优先简单单积分及少项常系数组合；复杂残留或暂时更多的有限方向不应未经调查就变成下一轮永久输入。参见[原空间选基](PRESERVE_ACTUAL_SPAN.zh-CN.md)。

## 6. 验收分层，不能跳级

执行顺序固定为**最高圈先闭合，再处理低圈**。搜索最高圈时，所有接触项和低圈源保留为符号，不为临时出现的源启动低圈 DE 或扩池。最高圈完整输入与两个方向导数闭合后，汇总最终源清单，再统一完成低圈系统和完整曲率核验。否则每次高圈引入新源都会重复低圈工作。

1. **候选筛查：** 通用单点的缺口下降或变为零，决定是否值得继续；不是精确闭合。
2. **关系有效性：** 完整作用、域、接触源与 symmetry 均通过当前实现的检查；联合池不能强迫已知非零低圈积分为零。
3. **有理重构与覆盖：** 多次采样重构系数，检查原 top、完整输入和两个方向导数；保留全部低圈系数，并独立核对全池查询残差。
4. **完整 DE：** 接入并验证所有低圈源，检查含高低圈耦合的完整曲率。最高圈齐次曲率零只验证该块，不能替代完整系统。

有限覆盖前先区分选基候选不足与关系不足。`FiniteSupportThenSpan` 在约化后原子全部单独有限时直接保留该支撑；只有出现非单独有限原子时才构造覆盖。候选可加入完整物理输入/导数的常系数多项式分块，每个候选必须同时通过物理有限性、约化后实际有理行空间成员关系和最终精确覆盖检查；分块本身不保证这些条件成立。

最高圈求秩和有限覆盖的系数矩阵应在提取系数**之前**投影掉低圈源，避免展开与该矩阵无关的大型源系数；原完整表达式必须另外保留，最终覆盖须重建这些源。`DeferBoundaryCoefficientSimplification -> True` 只推迟源系数的合并，不把它们设为零。同一轮前后两次请求完全相同的有限覆盖时，可以复用证书；缓存键包含完整行、约化规则、family、实现指纹和策略，不能跨扩池直接沿用。

三圈新工件分别记录了有理重构、全池通用**单点**核对与完整曲率**精确**零检查，不能合称“所有 IBP 残差都做了精确符号证明”。固定候选基复核也不证明旧池每轮历史有效、MI 全局最小，或四圈碰撞处方完备。

## 当前 package 入口与自动化边界

已加载 package，且 `family`、`residualTargets` 与完整历史应用/对称账本已准备好时，可用以下接口生成一批候选增量：

```wolfram
candidateBatch = GenerateSystem[family, residualTargets,
  "SeedGeometry" -> "InverseTargets",
  "InverseOperatorPolicy" -> "Complete",
  "SeedDomain" -> "Original",
  "CompletedApplications" -> completedApplications,
  "CompletedSymmetryInputs" -> completedSymmetryInputs];
```

只有实际需要且 family 已声明相应 supersector 时才改为 `"Extended"`。这段代码是生成入口，不能替代候选收益筛查、扩池后重放与完整 DE 验收。

| 能力 | 当前边界 |
| --- | --- |
| 逆移位选择种子与适配算符补全 | 已实现；显式选择 `InverseTargets`，通用默认几何仍为 `ComponentAxial`；`Complete` 是逆向模式的默认算符策略 |
| 应用去重、增量 symmetry、campaign 扩池重放 | 已实现；单独调用 `GenerateSystem` 返回生成结果，不替调用者管理历史主池和 DE 重放 |
| 候选复杂度审查 | 已实现；`ComplexityReviewRequired` 保存诊断，尚不自动遍历全部辅助壳层/coupled 修复策略 |
| coupled 搜索 | 已实现显式 seed 组接口及独立认证；不保证全域完备，不自动选择所有值得搜索的组 |
| 逐批收益调度和递归低圈闭合 | 三圈实验脚本有专项流程；通用 `RunDE` 尚未自动完成本文整套决策，也不递归闭合低圈系统 |

现有回归入口包括 [CompleteInverseActions.wls](../Tests/CompleteInverseActions.wls)、[ContactSourceValidity.wls](../Tests/ContactSourceValidity.wls)、[SeedDeduplication.wls](../Tests/SeedDeduplication.wls) 和 [ClosedPoolReplay.wls](../Tests/ClosedPoolReplay.wls)。本次整理只更新经验文档，不改变运行默认值或重新执行三圈大规模计算。
