# 用实际物理行的坐标检验秩和有限覆盖

四圈计算中，符号RREF可能比所需的DE坐标复杂得多。可先从本轮输入和导数中选取有限、独立的物理表达式，再用FiniteFlow求其余行在这些表达式上的坐标。此方法只改变线性代数的输出目标，使用同一组已约化并核对过的行，不增加积分关系。

设本轮正规形矩阵为M，选出的行构成B。先在无极点的有限域点找到B的非零r阶子式，证明秩至少为r；再重构W并逐项精确验证M=WB，证明秩至多为r。两项检查共同证明精确秩为r。单独的数值秩不能替代后一个检查。

如果对应的物理表达式均通过有限性判据，B同时给出r项有限覆盖。选出的基可能含变量系数：应优先检查物理输入、导数中的常系数表达式及常系数块，记录搜索范围、已验证方向及采用变量系数后备项的原因。某个有限候选集没有找到足够常系数方向，不等于证明所有常系数代表都不可能。

2026-09-26的独立四圈测试使用epoch 5较小基路线第六轮的63行、224列矩阵。全部63个物理表达式通过有限性检查，从中选出的30行具有非零子式，所有63行的坐标残差精确为零，故联合秩为30且30项有限覆盖成立。此次坐标重构最高次数12，整个测试约77秒；同一矩阵的RREF重构最高次数168，系数采样重构约315秒，之后仍需较长的精确残差化简。时间包含不同计算内容，不能直接当作通用加速比。

原始物理方程、完整源依赖及完整池数值核对均保留。这里计算的是最高圈商空间；通过此测试不代表完整四圈DE已闭合。脚本位于独立实验目录 `neatibp-evaluation-20260926/`，冻结的`source-v7`和通用Kernel接口未修改。

后续常系数优先搜索已成功：第六轮43个候选提供30个独立常系数方向，最终30项有限基全部为常系数，且通过精确成员资格、覆盖及有限性检查。第七至九轮也分别得到42、57、75项常系数有限基，项数均等于各轮实际联合秩。

2026-09-27进一步优化计算次序：数值秩见证先代入运动学点再提取系数；新物理行及新候选的正规形由FiniteFlow直接重构；精确残差只分配积分因子，再逐个标量系数检验恒等式，避免先展开全部多项式。第六轮完整回归得到与原实现完全相同的30项基，精确覆盖通过，耗时约75秒；原预筛选实现约541秒。该时间对比来自本机这两个具体运行，不是一般复杂度结论。

重放旧轮次时，证书必须绑定同一完整池、同一物理输入与导数，并重新通过完整池数值正规形检查。第六至九轮原生证书与输入秩见证的一次复核约18秒。原始精确证书仍是联合秩上界的依据，数值子式只证明下界，不将数值秩单独当成精确秩。

## 0.6.0 package 接口

`RunPhysicalCoordinateDE` 已整合物理行直接坐标重构、按池/输入/源码绑定的物理求导缓存、完整池单点参考、常系数候选块、超限幂次项的精确常系数消去及按传播子类型的硬上限。选出的有限基按实际联合秩验收，不按原子个数计数。源项保留在原始物理池与依赖清单中，最高圈投影不宣称完整含源 DE 已闭合。

可用 `"FiniteReferenceBasis" -> candidates` 指定一组独立有限候选作为坐标参考。每轮先在当前完整物理池中重新求出输入和导数在这些候选上的有理坐标，再只取实际空间所需的独立有限组合；不会把全部候选当成下一轮输入。优先选常系数组合；不足时可选含运动学系数的完整有限组合。候选不覆盖当前物理行、并非独立或有限性失败时返回失败，不强行投影。该选项只复用物理积分定义，不导入既有 DE 矩阵或约化规则。

这还避免了一种代表选择问题：有限 IBP 池未必包含其中每条恒等式的所有运动学导数。两组代表在当前池中张成相同空间，不保证继续对两组原始表达式求导后仍得到相同空间。保留已知低幂有限候选作为物理坐标参考，或补足合法求导关系，均需按当前池重新验证，不能把这种增长直接解释为真实主积分数增加。

达到候选闭合后，`scripts/verify-physical-coordinate-run.wls` 重新做完整池数值求解，重新计算原生导数，并核对有限性、独立性、DE、数值齐次曲率及原 Top 有理覆盖。符号完整池残差与符号曲率不是默认流程。

## 完整含源系统

最高圈独立验证通过后，可用 `ReconstructFiniteCoordinateSystem[families, basis, originalInputs, physicalEquations, "OutputDirectory" -> path]` 接回低圈有限候选。`families` 按圈数关联完整的 `CreateFamily` 返回值；从导出的精简配置读取时，先重新调用 `CreateFamily`，再核对 family hash。该接口重新计算各圈原生导数，将能映射的接触源转为已声明低圈 family 的积分；其余接触源仍作为独立的 `BoundaryIntegral` 列保留在完整物理池中。完整坐标重构使用 `RetainAll` 模式，数值秩检验和有理坐标重构都保留这些列，任何未消去的源项都会阻止闭合验收。只有最终 DE 完全回到已声明的有限基上，才检查完整矩阵、独立性、原 Top 覆盖与单点曲率。低圈候选项数暂时保留，不据此声称低圈覆盖也已最小化。

`scripts/verify-finite-coordinate-system.wls RUN FINITEFLOW_ROOT [PACKAGE_ROOT]` 在独立进程中重新求导、重新做完整池数值约化，核对保存矩阵和原 Top 坐标。默认仍只检查一个非奇异有限域点，不做符号残差或符号曲率化简。

方向链的数值支撑在模素数归一化后才记录，避免整数倍素数的零系数造成虚假支撑。普通 `RunDE` 的同池断点续算保留之前的首次出现轮次；关系池变更后从 Top 重放并重建链历史。

## 四圈：简单低幂覆盖先闭合，闭合后压缩

按最新指示，四圈使用 `"FiniteCoverPolicy" -> "LowPoleClosureFirst"`。它优先选择低幂、少支撑的有限代表，允许覆盖空间比当前输入＋导数空间大。例如当前只需要 `I1+I2`，仍可先保留简单的 `I1,I2` 来研究闭合；不会为了把项数压到秩数而强制选择复杂组合。候选先按低幂和结构简单度排序，在完整池的数值正规形中选独立代表，再删去当前覆盖完全不需要的方向。

覆盖数大于实际秩时，两者分别做有理坐标重构：一份证明输入与导数确实被简单代表覆盖，另一份证明它们当前实际张成的秩。每轮明确报告 `RationalJointRank` 与 `CoverBasisCount`。70 门槛仍作用于实际联合秩，三次方向链增长仍触发关系修复。覆盖较大不会替代闭合验证；最终必须对同一组有限输入重新求导并回到该组空间。

闭合后，将已闭合的低幂有限定义传作 `FiniteReferenceBasis`，用默认 `PreserveActualSpan` 从 Top 重放以压缩覆盖，随后再次独立验证。四圈配置见 [four-loop-physical-closure-policy.wl](../Examples/four-loop-physical-closure-policy.wl)。三圈既有对照继续采用实际空间压缩策略。

四圈余量按比例定标：[三圈复核数据](THREE_LOOP_COVER_SLACK_0.6.0.json)。定义 δ=(覆盖项数−实际秩)/实际秩。有效历史记录中，ladder 首轮 δ=1/3，tennis 首轮 δ=1，其他有效轮次为 0。用户指定取三圈浮动的 150%，因此相对超额上限为 3/2；`MaxRelativeCoverExcess -> Automatic` 当前采用这一比例。每轮的覆盖项数上限为 `Floor[(1+3/2) rank]`，额外方向上限随秩计算，禁止固定项数余量。

比例上限是容许范围，选基仍尽量贴近实际秩。超出时尝试保留有限数量的简单积分并以短组合补齐；所选代表的外点—圈点分母正幂上限为 3，圈点—圈点上限为 2，不能提高幂次来凑项数，不能满足时返回 `SimpleCoverCountTradeoff`，要求补候选或关系。每轮记录实际相对超额和由当前秩推导的整数上限。

旧 tennis 第四轮物理输入在修正池下联合秩为 32，当时保存的 31 项覆盖未通过此次覆盖复核，已排除出定标样本；最终 31 项闭合基的单独验证仍成立。

完整系统接口支持 `CanonicalPhysicalPoolCaches -> {indexFile, ...}`，把已缓存的完整规范化物理池与显式 equations 参数中的附加物理行合并。每个缓存必须通过文件 SHA-256、物理行哈希、family 哈希和保留源信息校验；只复用已规范化物理积分标签，不复用旧 DE 作为关系。完整数值参考另存为 `FullReference.mx`，方便在候选相关或覆盖不足时进行后续选基。
