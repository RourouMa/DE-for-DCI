# 接触源有效性与联合池一致性

本实现的普通 IBP 使用零散度、切于 `Y_i^2=0` 的旋转向量
`v_i=(Y_i.A) B-(Y_i.B) A`。生成器排除 `A=Y_i`、`B=Y_i`。因此不能把接触项矛盾简单归因于所有含环点 `Y_j` 的算符，也不能通过禁用这些必要算符来替代边界检查。

## 已定位的漏检

旧 `contacts` 只统计同一求导端点的双极点。三圈 seed 的内部幂次为 `(2,2,0)` 时，沿链末端求导可能只命中一个双极点，却在收缩后留下仍具有双极点的二圈源。只检查当前端点不足以排除这种连续碰撞。具体复现见 `Tests/ContactSourceValidity.wls`：

```
seed = G[2,0,0,0,0,0,1,0,0,0,2,0,2,2,0,1,1,1]
v_3 = (Y3.X3) Y2 - (Y3.Y2) X3
source = -2 BoundaryIntegral[2,{2,0,0,0,0,0,2,0,2,1,1}]
```

发散源项不能在缺少一致正则化或完整多重接触处方时，直接与独立的四维低圈关系混用。这里并未证明每条含发散源的形式关系必然错误；现有实现不能认证它们，必须明确拒绝而不是截去源项。

`regularContactSourcesQ` 在**整个收缩源表达式**层面调用保守有限性判据。同一圈数的源先作为整组合检查，允许已支持的精确碰撞留数抵消。不能认证的普通或 coupled 关系返回 `UncertifiedContactSource`，不进入池。该检查不实现嵌套碰撞的正则化，也不宣称对四圈所有有限组合完备。

## 池与验证的管理

- 加强生成器后，历史关系不能仅凭旧“通过”标志继续视为有效。保存旧池供审计；更正关系时记录明确排除原因、生成器版本和新旧证书，从原 top 重放。保留旧关系的要求适用于仍然有效的关系。
- 数值残差通过表示重构符合给定关系池，不等于关系池符合积分定义。检查已知非零低圈积分是否被强制为零，并分别验证齐次曲率与完整曲率。
- 接触项的有限性在低圈自身的 family 中判断，采用相同外部运动学和标准传播子次序。横向与纵向子拓扑的映射分别保留。
- 接触项消去、有限覆盖、查询覆盖和原子规范化是不同操作。拒绝不受支持的关系不等于将发散积分置零。

2026-09-23 的旧 tennis 联合池有 311 行精确矛盾证书，可把一圈 box 消为零。隔离发散二圈接触源的实验恢复了 box，得到完整曲率为零的 46 维候选；当时仍缺少历史关系有效性复核，此前 31 维齐次块继续隔离。

随后用修正 package 重新执行全部 708301 次 seed/operator 应用，没有导入旧方程、约化或 symmetry 缓存。新联合池重新给出 tennis 的低圈依赖，且其求导关系精确成立；46 维完整曲率 2116 项为零，一圈基未被消为零。同时，定向补齐合法算符后，ladder 的 30 维矩阵原样重现，完整曲率 900 项为零。新结果及验证范围见[完整复核记录](../reproduction/corrected-three-loop-20260923/README.zh-CN.md)。新证书不适用于已隔离的旧方程池。
