## 后续执行原则

1. 首先满足原生有限性、完整物理关系池覆盖、原生求导闭合与独立验证。不得为了减少覆盖项数丢弃低圈源列。
2. 所选分母正幂保持硬上限：Xa·Yi <= 3，Yi·Yj <= 2；分子负幂不计入。此限制不删除求解所需的 IBP 行和原生导数目标。
3. 在这些约束下，优先原子积分，其次是短的常系数组合。含运动学系数的长组合应作为需要明确审计代价的备选，不应只因项数较少就自动优先。
4. 每次精致压缩都同时记录：覆盖项数、实际联合秩、组合支撑长度、运动学系数组合数量、矩阵非零元数量、约分后分子/分母次数、单项式数和表达式长度。必须与压缩前的闭合基比较。
5. 若项数减少伴随矩阵元明显膨胀，应保留更简单的原子基或尝试中间规模的短常系数基。不能把“覆盖项数减少”表述为“整体表达式复杂度改善”。任何替换仍需重新检验闭合。
6. 四圈继续低幂简单覆盖先闭合、闭合后再做结构压缩；覆盖项数尽量靠近当前实际秩，但允许稍多。比例预算按每轮 `(cover-rank)/rank` 计算，当前由三圈历史校准得到上限 3/2；上限不是目标，也不是固定多若干项。不同已闭合基之间的项数差不应冒充该轮实际秩超额。
7. 四圈实际联合秩上限仍为 70；固定方向链增加至少 3 次时扩大有效 IBP / symmetry / 已证明的物理关系，并从 Top 重放。不能靠继续推进同一缺关系系统规避该规则。
